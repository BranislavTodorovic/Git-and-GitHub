# Beginner Web Calculator

## Purpose
This project is a small browser calculator for everyday whole-number and decimal arithmetic.

## Technology
Use plain HTML, CSS, and JavaScript with no dependencies, framework, backend, or build step.

## Authority and scope
The `BRD.md` in the related personal-web-calculator project is the authority for required behavior. Keep this implementation beginner-friendly and explainable. Do not add history, scientific functions, percentages, memory, parentheses, complex expressions, authentication, saved data, keyboard support, or external integrations.

## Verification
Open `index.html` directly in a browser and manually check the required operations, decimal and zero entry, results, continued calculations, clear/reset, and recoverable division by zero. Inspect the source for obvious syntax and requirement issues.
